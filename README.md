# Jewelry-Shop

Проект: «Jewelry Shop» — веб-приложение для продажи ювелирных изделий

Роль: системный аналитик 

Этапы создания:

1. Проектирование архитектуры приложения: Определила клиент-серверную архитектуру. Выделила фронтенд-часть (статичные файлы index.html, style.css, script.js в папке public) и бэкенд-сервер (server.js на Node.js).
2. Моделирование данных (Data Modeling): Разработала структуру каталога товаров. Создала файл data/jewelry.js в качестве mock-данных (эмуляция базы данных), описав структуру объекта товара (поля: название, цена, описание, категория).
3. Описание взаимодействия (API): Спроектировала логику работы сервера server.js. Определила, какие эндпоинты должны быть реализованы для работы магазина (например, GET /api/jewelry для получения списка всех товаров, GET /api/jewelry/:id для карточки товара). Описала методы HTTP (GET) и ожидаемые статус-коды (200 OK, 404 Not Found).
4. Управление зависимостями: Проанализировала и описала зависимости проекта в package.json (например, библиотека Express для сервера), чтобы обеспечить воспроизводимость сборки.
5. Документирование: Подготовила файл README.md с описанием проекта, инструкцией по запуску (скрипт старт) и описанием структуры папок.

Стек и инструменты, задействованные в проекте:

· Архитектура: Клиент-серверная архитектура (REST API).

· Форматы данных: JSON (структура данных в jewelry.js).

· Инструменты: Git, GitHub, Node.js, Express.

· Анализ: Проектирование структуры данных и пользовательских сценариев (просмотр каталога, выбор товара).
